## Profile

I'm an indie developer building web and iOS apps that reduce the small chores that come up again and again in daily life. I used to build one-off tools for problems friends and family brought to me; now I package that experience into apps anyone with the same problem can use as-is.

- **What I build:** iOS / Android / Web apps, browser tools, WebXR, and embedded integrations such as Stack-chan
- **What I care about:** publishing why an app exists, where its data lives, and its known limits, so people can decide before they use it
- **How I verify:** claims are backed by public repos, source files, and test results; anything unverified is labeled as such

**Website:** [okojo-it.com](https://okojo-it.com)  
**Contact:** [Contact form](https://forms.gle/1sVk1MEwX8diGxSo9)

<a id="policy"></a>

## Development Policy

- **Decide small, then build:** target user, required inputs, notification timing, and the features I will *not* build come first
- **Keep data on the device:** income, location, and school schedules are personal even when small, so I design local-first
- **Publish when it's decidable:** pages go public only once they contain enough information for users to make a decision
